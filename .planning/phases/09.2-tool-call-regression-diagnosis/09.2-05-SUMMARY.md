- **Fix:** Added a "CRITICAL CAVEAT — D-09 against the current test split" subsection inside Branch 06C, surfacing the 0.3422 vs 0.41 gap and enumerating three sub-options (renegotiate bar / swap measurement split / accept D-09 miss under D-02) for the user to pick among if the fallback is triggered.

- **Commit:** folded into the `c068400` DIAGNOSIS.md commit.
