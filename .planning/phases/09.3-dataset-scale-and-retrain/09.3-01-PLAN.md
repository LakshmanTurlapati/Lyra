<context>
The 09.2-07 rebalance proved subagent batches generate quality data: 31 parallel Agent-tool subagents produced 5,100 mode-collapse-avoiding samples in ~85 min wall-clock, each subagent writing JSONL directly to disk and returning a 1-line confirmation. 09.3-01 scales the same pattern from ~5K to ~42K samples by running ~14 sequential batches, each with 5-10 parallel subagents, totalling 155 deterministic generator scripts.

Each generator is a standalone Python file (no Anthropic SDK, no external API) that:
- Reads system prompts and tool/topic data from companion `_data*.py` modules or `templates/knowledge-topics-v2.yaml`
- Uses a fixed seed + `hashlib` per-sample for deterministic variation
- Reuses the 30-variant `SUFFIX_POOL` from 09.2-07's `07-SUFFIX-POOL.md` for multi-turn assistant-ending diversity
- Writes ShareGPT-shaped JSONL to a deterministic path under `datasets/<domain>/raw-09.3/`
- Validates structure implicitly — 09.3-02's curate pipeline runs `Conversation.model_validate()` as the hard gate

Generator naming convention:
- `gen_tc_09_3_<LETTER>[<N>].py` — tool-call slice (LETTER = domain cluster A-H, optional N = re-run with different sub-domain)
- `gen_code_09_3_<LETTER>.py` — code slice (LETTER = batch group)
- `gen_knowledge_09_3_<LETTER>.py` — knowledge slice (LETTER = batch group, drawing topics from v2 YAML)

Each generator-letter slice writes exactly 100, 300, 500, or 1,500 samples depending on the batch wave.
</context>
